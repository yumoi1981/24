# 公民トロッコアドベンチャー

中3公民 第2章「個人を尊重する日本国憲法」（教科書 p.44〜49・資料集 p.34〜45）を、ネプリーグのトロッコアドベンチャー風に覚えるブラウザゲーム。

- 15コース（追加：身体の自由と袴田事件）＋全範囲ミックス、2択325問
- 5問連続正解でクリア、1問でもまちがえると転落
- 制限時間は設定で変更（5〜30秒・なし）
- 正解・不正解どちらでも、両方の選択肢の解説と用語カード（もっと知ろう）を表示
- 用語集（232語）：コース別の絞りこみ・検索つき
- むずかしい用語にはふりがな
- 記録は端末（ブラウザ）に保存

`index.html` を開くだけで遊べます。
